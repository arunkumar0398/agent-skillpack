# Theme Palettes

10 pre-built palettes aligned with design movements. Each includes hex codes, font stacks, and mood descriptions. Use these as starting points or adapt them to your philosophy.

---

## 1. Bauhaus Modernism

**Mood:** Rational, geometric, bold — form follows function.

| Token | Hex | Usage |
|-------|-----|-------|
| Primary | `#E63946` | Bold accents, CTAs |
| Secondary | `#457B9D` | Secondary actions, links |
| Accent | `#F4A261` | Highlights, badges |
| Background | `#F1FAEE` | Page background |
| Surface | `#FFFFFF` | Cards, containers |
| Text Primary | `#1D3557` | Headings, body |
| Text Secondary | `#6B7280` | Captions, metadata |

**Fonts:** Space Grotesk (headings) + DM Sans (body) + JetBrains Mono (code)

## Usage

To apply a theme, run:

```bash
./scripts/apply-theme.sh bauhaus-modernism
```

Or reference the hex codes and font stacks directly in your philosophy document and implementation.
