# Anti-AI-Slop Rules

A reference guide of 20+ rules for avoiding generic AI-generated aesthetics. Every visual output must be checked against this list before shipping.

## Color Rules

1. **No purple gradients.** Purple gradients (especially blue-to-purple, pink-to-purple) are the single strongest signal of generic AI output. Use intentional, philosophy-grounded palettes instead.
2. **No rainbow or spectrum effects.** Multicolor gradients without restraint look like default settings.
3. **No neon colors on dark backgrounds without purpose.** Neon-on-dark is overused; only apply when the philosophy demands it.
4. **No pure black (#000) and pure white (#FFF) as primary colors.** Use off-blacks (#1a1a1a, #111) and off-whites (#fafafa, #f5f5f0) for warmth and sophistication.
5. **No equal-saturation palettes.** Vary saturation levels — muted backgrounds, saturated accents, desaturated neutrals.
6. **No pastel-everything.** Pastels without contrast look washed out and juvenile. Balance pastels with deeper tones.

## Typography Rules

7. **No Inter as default.** Inter is overused in AI-generated designs. Choose a typeface with personality.
8. **No centering all body text.** Left-aligned (or justified) body text is more readable and shows intentional alignment.
9. **No font sizes below 14px for body.** Accessibility requires readable text.
10. **No font-weight uniformity.** Use weight contrast (300 vs 700, 400 vs 800) to establish hierarchy.
11. **No more than 3 font families.** Most designs need only 2: one for headings, one for body. Mono is optional for code-heavy contexts.

## Layout Rules

12. **No centered-everything.** Asymmetric layouts, left-aligned headings, and intentional grid placement show craft.
13. **No equal spacing between all elements.** Use a spatial scale (4px, 8px, 16px, 24px, 32px, 48px, 64px) with clear rhythm.
14. **No full-bleed sections stacked vertically without variation.** Alternate widths, use insets, break the pattern.
15. **No uniform card grids without hierarchy.** Vary card sizes, use featured cards, break the grid intentionally.
16. **No hero section + 3 feature cards + CTA + footer template.** That's the AI default layout. Find a composition that serves the content.

## Shape and Decoration Rules

17. **No uniform rounded corners.** Use varied radii (2px, 4px, 8px, 12px, 16px) based on element context and importance.
18. **No drop shadows on every element.** Use shadows sparingly — 1-2 elevation levels maximum.
19. **No glassmorphism by default.** Frosted glass effects are a crutch. Only use when the philosophy explicitly calls for translucency.
20. **No decorative blobs or gradients as background filler.** Backgrounds should be intentional colors or textures, not random shapes.

## Content Rules

21. **No placeholder or filler text.** Use real, meaningful copy that demonstrates the design in context.
22. **No generic icon sets without personality.** Choose icons that match the design's character — hand-drawn, geometric, monoline, etc.
23. **No lorem ipsum.** Even in prototypes, use realistic content that shows the design at its best.
24. **No "Welcome to Your Dashboard" or similar generic headings.** Write specific, contextual copy.

## Interaction Rules

25. **No hover effects on everything.** Not every element needs a hover state. Apply interaction only where it aids usability.
26. **No animations without purpose.** Animations should communicate state changes, not decorate.
27. **No transitions longer than 300ms for UI elements.** Fast feedback is more important than smooth motion.

## Quick Checklist

Before finalizing any visual output:

- [ ] Would this design be indistinguishable from any other AI output?
- [ ] Can you name the design movement it draws from?
- [ ] Is every color justified by a principle, not a default?
- [ ] Would a designer look at this and say "this was intentional"?
